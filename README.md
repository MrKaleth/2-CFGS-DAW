## Introducción

Este repositorio recopila el trabajo realizado durante el segundo curso del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web.

Su contenido se irá ampliando progresivamente a medida que avance el curso. Actualmente, el repositorio se encuentra en una fase inicial, ya que el curso comenzó recientemente.

La información general del ciclo se basa en la descripción oficial del título de Técnico Superior en Desarrollo de Aplicaciones Web, perteneciente a la familia profesional de Informática y Comunicaciones. El ciclo tiene una duración oficial de 2.000 horas. [TodoFP](https://www.todofp.es/que-estudiar/familias-profesionales/informatica-comunicaciones/des-aplicaciones-web.html)

### Competencia general

La competencia general de este título consiste en desarrollar, implantar y mantener aplicaciones web, garantizando el acceso a los datos de forma segura y cumpliendo los criterios de usabilidad, accesibilidad, calidad y funcionalidad establecidos.

Durante el ciclo se trabajan, entre otras, las siguientes capacidades:

- Configurar y administrar sistemas informáticos y servidores de aplicaciones.
- Gestionar bases de datos, garantizando su integridad, consistencia, seguridad y accesibilidad.
- Desarrollar aplicaciones web conectadas a bases de datos.
- Aplicar técnicas de seguridad en sistemas, servicios y aplicaciones.
- Diseñar interfaces web accesibles, usables y adaptadas a diferentes dispositivos.
- Desplegar y mantener aplicaciones web en diferentes entornos.
- Utilizar herramientas de control de versiones, documentación y trabajo colaborativo.

### Requisitos de acceso

Para acceder a un ciclo formativo de grado superior es necesario cumplir, al menos, uno de los siguientes requisitos:

- Estar en posesión del título de Bachiller.
- Estar en posesión de un título de Técnico de Grado Medio.
- Estar en posesión de un título de Técnico Superior, un título universitario o una titulación equivalente.
- Haber superado una prueba de acceso a ciclos formativos de grado superior.
- Haber superado un curso de formación específico preparatorio para el acceso a ciclos de grado superior.
- Haber superado una oferta formativa de Grado C incluida en el ciclo formativo.

En mi caso, el acceso se realiza tras haber completado el Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma.

### Información adicional

El ciclo formativo tiene una duración oficial de **2.000 horas**, distribuidas en dos cursos académicos, incluyendo los módulos profesionales, el proyecto intermodular y la formación en empresa u organismo equiparado, conforme a la organización establecida por la administración educativa.

Este repositorio corresponde al curso **2026/2027** y contiene únicamente los módulos cursados en segundo curso. No se incluyen los siguientes módulos:

- Itinerario personal para la empleabilidad.
- Sostenibilidad aplicada al sistema productivo.
- Inglés Profesional.
- Módulo profesional optativo.

Estos módulos no forman parte de mi itinerario académico actual al haber realizado previamente el Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma.

## Módulos

Las carpetas del repositorio reciben el nombre completo de cada asignatura. El contenido se incorporará progresivamente durante el curso.

### Desarrollo web en entorno cliente

Materiales, ejercicios y prácticas relacionados con el desarrollo de aplicaciones web ejecutadas en el navegador, utilizando tecnologías del lado del cliente.

### Desarrollo web en entorno servidor

Apuntes, ejercicios y proyectos relacionados con la programación del lado del servidor, la gestión de sesiones, la conexión con bases de datos y la creación de aplicaciones web dinámicas.

### Despliegue de aplicaciones web

Contenido relacionado con la configuración de servidores, la publicación de aplicaciones web, la administración de entornos de ejecución y los procesos de despliegue y mantenimiento.

### Diseño de interfaces WEB

Materiales y prácticas sobre el diseño y desarrollo de interfaces web accesibles, usables, adaptables y coherentes con los requisitos de cada aplicación.

### Proyecto intermodular de desarrollo de aplicaciones web

Proyecto final en el que se integrarán los conocimientos y competencias adquiridos en los diferentes módulos del ciclo.

### Formación en empresa u organismo equiparado

Documentación y materiales relacionados con el periodo de formación en empresa u organismo equiparado, cuando corresponda.

## Organización del repositorio

La estructura del repositorio se mantendrá sencilla y se ampliará conforme avance el curso. Cada módulo contará con una carpeta cuyo nombre coincidirá con el nombre de la asignatura correspondiente.

El contenido de cada carpeta podrá incluir:

- Apuntes y documentación.
- Ejercicios y actividades.
- Prácticas de clase.
- Proyectos.
- Recursos complementarios.
- Documentación técnica.

La organización podrá cambiar a medida que aumente el volumen de materiales, procurando mantener una estructura clara y fácil de consultar.
