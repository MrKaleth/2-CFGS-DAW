# EV03 · Taller de impresión 3D

Ejecuta estos comandos desde la carpeta que contiene package.json.

```sh
npm install
npm run dev
```

Abre la dirección que indique Vite. Utiliza Node.js 20.19+ o 22.12+ dentro de sus respectivas ramas, o una versión posterior compatible.

- `src/App.jsx` reúne los componentes iniciales.
- `src/components/` contiene el formulario, los controles de consulta, la lista y la fila.
- `src/data/pedidos.js` exporta los diez pedidos del enunciado.
