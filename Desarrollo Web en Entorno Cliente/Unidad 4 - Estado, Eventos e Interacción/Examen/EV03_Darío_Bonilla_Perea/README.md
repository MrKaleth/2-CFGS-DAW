# EV03 · Cartelera de un cine de verano

Requiere Node.js 20.19+ en la rama 20, o 22.12+.

Desde la carpeta que contiene package.json:

```sh
npm ci
npm run dev
```

Abre la dirección que muestra Vite.

La pantalla inicial contiene el formulario, los controles de consulta y los espacios de Programación y Cartelera. Los seis datos iniciales están en `src/data/peliculas.js`. Úsalos al completar la aplicación según el enunciado.

Entrega el proyecto sin la carpeta `node_modules` y añade `pruebas.md` con las dos comprobaciones solicitadas.
